# 🌐 3D Portfolio

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)

A personal portfolio built using React, Tailwind CSS, Three.js and Framer Motion. It highlights projects, skills, experience, and includes contact options. Designed for performance, accessibility, and visual clarity.

## 🛠️ Tech Stack 

- **Framework:** React, Vite
- **Animations:** Framer Motion, Parallax Tilt
- **3D Model & Custom shaders:** Three.js, R3F, and drei 
- **Styling:** Tailwind CSS
- **Icons:** Lucide React
- **Deployment:** Vercel
